# Electromagnetism

**Electrical lighting, electronics, and instruments for Create: Electro Energetics.**

## Electrified running rails

Place an Electro Energetics single connector directly under a straight track block and wire its terminal to the supply. Both running rails carry the same potential. Place an Electro Energetics insulator directly under another straight track block to divide the conductor while keeping the track passable. Wheels on the same train can bridge the joint while straddling it.

| Supply | Overhead wires | Rail feeder |
| --- | --- | --- |
| Single-phase AC | One pantograph on L | Supply return or neutral |
| Three-phase AC | Two laterally separated pantographs, one on L1 and one on L2 | L3 |

Fit a CEE train motor. The collectors feed the traction bus through a bridge rectifier. Standard, wide and narrow running tracks use Create's track graph and the bogey's travelling points. Existing mechanical gauge restrictions apply to Blocks & Bogies styles.

Independent electrical circuits advance on solver workers. The server thread waits for all participating circuits and applies their accepted results within the same tick. A simulation step that takes longer than 50 ms extends the server tick.
