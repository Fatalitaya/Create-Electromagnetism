Open-circuit alternator repair ? 2026-11-16

Root cause
Alternator windings are modeled as an ideal source, series inductance and copper loss. With open terminals the inductor is an electrical cut edge. KCL forces its current to zero. Explicit zero-flux initialization repeated the zero-current constraint and did not determine the inductor voltage, producing a singular Jacobian. This happened before useful observations reached the server/client displays.

Repair
Rust initialization detects inductor cut edges using the electrical port graph. For zero initial flux on an open winding it uses the consistent zero-derivative condition (zero inductor voltage); KCL still enforces zero current. No leakage conductance, artificial load, flux reset or numerical diagonal regularization is introduced. Nonzero initial flux on an open inductor is explicitly rejected. Loaded inductors keep their original flux constraints. Normal transient equations are unchanged.
During live validation a separate Java boundary guard incorrectly paused assembly startup merely because a reading had a torque field, even when torque was zero. The guard now permits zero-torque transitions when bindings still match; nonzero-torque boundary checks and explicit world-effect acknowledgement remain in place.
