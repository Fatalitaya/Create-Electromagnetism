Implemented behavior

CEE destructive device branches now follow CEE componentDamage before native protection evaluates them. Fuse blocks, fuse-holder fuse inserts and panel MCBs retain their protective function. Mod lamps and heaters retain their own existing componentDamage scope. Wires independently follow CEE wiresBreak, including tapped conductors. Thermal current, loss and temperature remain simulated when damage is disabled.

NativeProtection supplies common gauge and indicator parameters for standalone devices, panel parts and holder indicators. Branch ownership is checked for destructive thermal branches. SF6 halves and paired transformer cores are validated before whole-assembly destruction; existing current-transformer, bulb and fuse-holder effects remain separate. Negative-facing orphan transformer halves now report the same missing-pair blocker.

A primary 1 Gohm voltage-probe input matches the existing secondary probe, fixing the singular initial system observed when an unpowered transformer core pair was placed. The initial-state contract still rejects genuinely inconsistent constraints.

Thermal trip/no-trip models share a binding identity. Changing permission preserves accepted thermal state and no longer pauses as a model replacement. Adding devices/connections while older inputs are queued is allowed only when all historical owners, terminals and branches remain present unchanged. Removal, replacement, rewiring and mechanical-boundary checks remain strict. Transaction revisions, candidate/accepted separation and world-effect acknowledgement remain in place.

The existing tapped-wire trip parameter uses zero to mean no destructive threshold. Java constructs this parameter and Rust decodes it to None; Rust encoding retains its fixed parameter slot. No internal compatibility version was introduced. Metadata remains the compatibility authority.

/electromagnetism native coverage now reports registered type, position, stable identity, adapted/blocked status and actual capture blockers. The legacy inventory helper only audits identities; runtime coverage uses actual native capture rather than descriptor interfaces or fixed unverified messages. Unknown devices still produce explicit blockers.

Reproduction

From the repository root use python docs/validation/run-autojs.py <script> server (or client). The endpoint is the existing local AutoJS service on port 25585. Scripts are sequential and share AutoJS globals. Use a copied disposable world, never an existing user build.

Gauge order: gauge-setup, gauge-connect after node registration, gauge-overload, gauge-observe, gauge-enable-damage, gauge-observe. Allow ticks and inspect progress between changes.

Pair order: pair-source, pair-setup, pair-connect after nodes exist, pair-overload, pair-observe. The experimental pair-atomic attempt is retained only inside the transcript: placement alone does not immediately register wire nodes.

Valid panel order: pair-source in a fresh copy, panel-setup, panel-connect after node registration, panel-observe, panel-reset, panel-observe, panel-off, panel-observe, checkpoint-observe. Leave/reopen with the client scripts, then restart-observe. Do not rerun placement scripts on an already populated fixture.

Source-only completion (latest user direction: skip all tests)

The source patch now includes the remaining identified scheduling and boundary fixes. No build, test, benchmark or in-game run was performed after this instruction. Earlier pass/fail results describe earlier source revisions only.

Rust protection localization retains only its unaccepted time bracket across cooperative deadlines. The upper-bound candidate is recomputed against the current observation window, preventing replay of integrated energy or waveform samples. Every parameter/topology/input/energy mutation invalidates the bracket, and restore reconstructs it from accepted state rather than persisting speculative work. Existing numerical tolerances, event acknowledgement, wire layout and metadata compatibility are preserved.

The coordinator dispatches up to four identical passive captured intervals per worker request, while retaining individual history entries and consuming only accepted time. Waveform, audio and mechanical workloads retain their separate captured windows. The world accepts finished work at tick start and end without blocking or deleting history. FE/fluid handlers are attempted only at a fully accepted idle boundary, so busy native work does not waste their per-tick transaction attempt.

SF6 indication now uses accepted contact parameters. Protection/relay consumers are preflighted for the complete event boundary before the first mutation. Current-transformer stacks are captured and validated as full assemblies before damage, using the same member-identity safeguards as SF6 and paired cores. The existing specialized bulb, fuse-block, holder-insert and panel-MCB behavior remains separate.

Sable transfers reject unrelated destination owners, including same-type devices, and validate uniqueness of the complete successor identity map before swapping live ownership. This prevents overwriting another device's state or duplicating a stable identity. Invalid environment snapshots retain their original data and expose an UNAVAILABLE diagnostic rather than escaping the restore boundary.

The existing 64-device and attachment source inventory remains the implementation map. All remaining runtime scenarios remain UNVERIFIED at the user's direction. Source changes intended to address backlog and lifecycle failures have not been demonstrated to resolve those failures by a new run.
